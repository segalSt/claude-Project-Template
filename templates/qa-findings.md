# QA-находки (баги приложения)

Переиспользуемый шаблон — не привязан к конкретному проекту, копируется в
другие репозитории как есть. Баги ПРИЛОЖЕНИЯ, найденные при ручном
QA-прогоне по чек-листам (раздел "Ручное QA" шага плана). В отличие от
`errors.md` (рассинхрон документации с кодом), здесь — реальные
поведенческие дефекты приложения.

**Процесс** (правило — `working-conventions.md`, раздел "Ручное QA по
чек-листу"):
- Во время прогона непрошедший пункт → строка сюда, статус `Open`.
- По завершении чек-листа — по каждому `Open`-багу спросить у пользователя,
  в какой шаг плана завести его задачей, и выполнить `-new` (задача в
  шаге); текст задачи — из описания бага.
- После починки бага → статус `Fixed` (и ссылка на шаг/задачу).

| id | Экран | Симптом | Ожидаемое поведение | Статус | Шаг/задача |
|---|---|---|---|---|---|
