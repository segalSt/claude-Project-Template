# История разработки (devHistory)

Переиспользуемый шаблон. Хронологический журнал сессий разработки - что
изменилось с прошлой сессии (дельта на человеческом языке), а не дубль
плана/спеки (те живут в `SPEC.md`/`plan.md`). Самая свежая запись -
сверху, добавляется в конце каждой сессии. Контекстный файл проекта
(аналог `tegExpertPrompt.md`) не пересказывает дельту в разделе "Прямо
сейчас" - только ссылается на самую свежую запись здесь + держит
критичный для продолжения минимум (что не закоммичено, что дальше).

**Когда разбивать на файлы (масштабируемая раскладка, тот же принцип, что
у `plan-template.md`).** Пока журнал небольшой - все сессии живут прямо в
этом файле. Когда чтение файла целиком становится дорогим (ориентир, не
догма - разбивать, когда `devHistory.md` превышает ~300-400 строк, или
сессий стало больше ~6-8) - разнести раскладку:
- в `devHistory.md` остаётся: **`## Индекс сессий`** (таблица: № сессии,
  дата, одна строка сути, ссылка на файл) + **полный текст ПОСЛЕДНЕЙ
  сессии, инлайн**, без открытия дополнительного файла;
- более старые сессии переносятся ДОСЛОВНО (без изменения содержания) в
  `history/session-<N>.md`, по одному файлу на сессию.

Перенос - механическая операция, ничего не переписывать по смыслу при
переносе. Контекстный файл проекта продолжает ссылаться сюда (индекс +
последняя сессия), не на файлы `history/`.
